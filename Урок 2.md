### Подключение стилей и базовая разметка

На прошлом уроке стили писались прямо внутри тегов через атрибут `style`. В реальной веб-разработке весь внешний вид выносят в отдельный блок или файл CSS (*Cascading Style Sheets* - каскадные таблицы стилей). Это позволяет разделять структуру страницы (HTML) и её оформление (CSS).

Стили внутри HTML-документа подключаются внутри тега `<head>` с помощью парного тега `<style>`. Внутри него пишется **селектор** (к какому элементу применить правила), а затем в фигурных скобках `{}` перечисляются свойства оформления:

```css
селектор {
  свойство: значение;
}

```

Чтобы оформлять конкретные элементы, им дают уникальное имя класса через атрибут `class="..."`. В CSS обращение к классу всегда начинается с точки `.`.

**Что делаем:**

1. Создаём стандартный скелет HTML-страницы.
2. В теге `<head>` добавляем блок `<style>`.
3. В `<body>` создаём тег ссылки `<a>` с классом `my-button` и текстом «Нажми на меня».

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Знакомство с CSS: Кнопка</title>
    <style>
      /* Базовые стили для всей страницы */
      body {
        background-color: #f0f2f5;
        font-family: Arial, sans-serif;
        text-align: center;
        padding-top: 50px;
      }
    </style>
  </head>
  <body>

    <!-- Наша заготовка кнопки -->
    <a href="#" class="my-button">Нажми на меня</a>

  </body>
</html>

```

> **Проверка:** Откройте файл в браузере. На светло-сером фоне появится стандартная синяя подчёркнутая ссылка без какого-либо кнопочного оформления.

### Пошаговое превращение ссылки в кнопку

Обычная ссылка - это строчный элемент (он занимает ровно столько места, сколько занимает сам текст). Чтобы ссылка стала кнопкой, ей нужно задать блочный режим, добавить отступы, убрать стандартное подчёркивание и скруглить углы.

Свойства CSS, которые для этого понадобятся:

* `text-decoration: none;` - убирает дефолтное синее подчёркивание у ссылки.
* `display: inline-block;` - позволяет элементу принимать внутренние отступы, ширину и высоту.
* `padding: 14px 28px;` - внутренние поля кнопки (14px сверху и снизу, 28px по бокам). Именно `padding` делает кнопку объёмной.
* `background-color: #2e7d32;` - фоновый цвет заливки.
* `color: #ffffff;` - цвет текста надписи.
* `border-radius: 8px;` - скругление углов.
* `cursor: pointer;` - курсор мыши превращается в указывающий палец.

**Что делаем:**

1. Находим в файле блок `<style>`.
2. Добавляем правило для селектора `.my-button`.

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Знакомство с CSS: Кнопка</title>
    <style>
      body {
        background-color: #f0f2f5;
        font-family: Arial, sans-serif;
        text-align: center;
        padding-top: 50px;
      }

      /* Оформление кнопки по классу */
      .my-button {
        text-decoration: none;        /* Убираем подчеркивание */
        display: inline-block;        /* Разрешаем отступы и размеры */
        background-color: #007bff;   /* Яркий синий цвет */
        color: #ffffff;              /* Белый текст */
        font-size: 16px;             /* Размер шрифта */
        font-weight: bold;           /* Жирный шрифт */
        padding: 14px 30px;          /* Внутренние отступы (высота и ширина) */
        border-radius: 10px;         /* Скругление краев */
        cursor: pointer;             /* Курсор в виде руки */
      }
    </style>
  </head>
  <body>

    <a href="#" class="my-button">Нажми на меня</a>

  </body>
</html>

```

> **Проверка:** Сохраните файл (`Ctrl + S`) и обновите вкладку (`F5`). Синяя текстовая ссылка превратится в современную объёмную прямоугольную кнопку с закруглёнными углами.

### Интерактивность: реакция на наведение (:hover)

Кнопка должна давать обратную связь, когда пользователь наводит на неё курсор или кликает. Для этого в CSS используются **псевдоклассы**:

* `:hover` - срабатывает в момент, когда курсор мыши находится над элементом.
* `transition` - делает смену цвета плавной, а не мгновенной (анимация за доли секунды).
* `box-shadow` - добавляет реалистичную мягкую тень под кнопкой.

**Что делаем:**

1. В класс `.my-button` добавляем свойство `transition: 0.3s;` для плавности.
2. Создаём новое правило `.my-button:hover`, которое меняет цвет фона на более тёмный и приподнимает кнопку тенью.

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Знакомство с CSS: Кнопка</title>
    <style>
      body {
        background-color: #f0f2f5;
        font-family: Arial, sans-serif;
        text-align: center;
        padding-top: 50px;
      }

      .my-button {
        text-decoration: none;
        display: inline-block;
        background-color: #007bff;
        color: #ffffff;
        font-size: 16px;
        font-weight: bold;
        padding: 14px 30px;
        border-radius: 10px;
        cursor: pointer;
        /* Плавность всех изменений за 0.3 секунды */
        transition: 0.3s;
      }

      /* Поведение при наведении курсора */
      .my-button:hover {
        background-color: #0056b3;                    /* Цвет становится темнее */
        box-shadow: 0 6px 15px rgba(0, 123, 255, 0.4); /* Мягкая синяя тень */
      }
    </style>
  </head>
  <body>

    <a href="#" class="my-button">Нажми на меня</a>

  </body>
</html>

```

> **Проверка:** Наведите курсор мыши на кнопку. Она должна плавно потемнеть и отбросить мягкую тень. Уберите курсор - кнопка плавно вернётся в исходное состояние.

### Задания для самостоятельной работы

Создайте карточку товара интернет-магазина (игровой предмет, кроссовки, мерч, гаджет или питомец).

#### Каркас карточки через контейнер `<div>`

1. Тег `<div>` - это универсальный прямоугольный блок-коробка, в который упаковывают другие элементы.
2. Создайте внутри `<body>` блок `<div class="card">...</div>`.
3. Внутри блока `<style>` создайте селектор `.card` со следующими параметрами:
* `width: 300px;` - фиксированная ширина карточки.
* `background-color: #ffffff;` - белый фон карточки.
* `border-radius: 16px;` - скруглённые углы карточки.
* `padding: 20px;` - внутренний отступ, чтобы текст и картинка не прилипали к краям карточки.
* `margin: 0 auto;` - центрирование самой карточки по центру экрана.
* `box-shadow: 0 4px 20px rgba(0,0,0,0.1);` - мягкая аккуратная тень вокруг карточки.



#### Наполнение карточки контентом

1. Внутрь блока `<div class="card">` вставьте картинку товара с классом `card-image`:
```html
<img src="ССЫЛКА_НА_КАРТИНКУ" class="card-image">

```


2. В стилях задайте для `.card-image`:
* `width: 100%;` - картинка займёт ровно всю ширину карточки.
* `border-radius: 12px;` - слегка скруглите углы самой картинки.


3. Добавьте название товара через тег `<h3>` (например, «Алмазный меч» или «Беспроводные наушники»).
4. Напишите короткое описание характеристик через тег `<p>` (2–3 предложения).
5. Добавьте цену через тег `<p class="price">` (например, «Цена: 1 990 ₽»).

#### Стилизация текста и цены

1. Для названия `h3` задайте свой цвет текста и уберите лишний отступ:
```css
h3 {
  color: #222222;
  margin-top: 15px;
  margin-bottom: 5px;
}

```


2. Для описания `p` сделайте серый неброский цвет: `color: #666666; font-size: 14px;`.
3. Для класса `.price` задайте крупный размер шрифта, жирность и контрастный цвет (например, зелёный):
```css
.price {
  font-size: 22px;
  font-weight: bold;
  color: #27ae60;
}

```



#### Кнопка «Купить» и эффект нажатия

1. В самом низу карточки разместите ссылку-кнопку:
```html
<a href="#" class="buy-button">Купить</a>

```


2. Напишите для `.buy-button` правила:
* Зелёный или оранжевый цвет фона (`background-color`).
* Белый цвет текста, отсутствие подчёркивания (`text-decoration: none`).
* Кнопка должна растянуться на всю ширину карточки: добавьте свойство `display: block;` и выравнивание текста `text-align: center;`.
* Внутренние отступы `padding: 12px;` и скругление `border-radius: 8px;`.


3. Добавьте псевдокласс `.buy-button:hover`, чтобы при наведении кнопка меняла цвет на более насыщенный.
4. **Эффект щелчка:** добавьте псевдокласс `.buy-button:active` (срабатывает в момент реального зажатия клавиши мыши):
```css
.buy-button:active {
  transform: scale(0.96); /* Кнопка слегка уменьшится, имитируя физическое нажатие */
}

```
