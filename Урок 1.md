### Создание скелета страницы

Любой сайт в интернете пишется на языке HTML (*HyperText Markup Language*). Браузер читает текстовый файл и выстраивает элементы сверху вниз. Чтобы браузер понимал, где настройки, а где контент, документ делится на логические зоны. Для этого используется базовый каркас («скелет»), состоящий из четырёх ключевых элементов:

**Что делаем:**

1. Создаём пустой текстовый файл и сохраняем его с именем `index.html`.
2. На первой строке объявляем стандарт `<!DOCTYPE html>`.
3. Открываем корневой контейнер `<html>` с атрибутом языка `lang="ru"`.
4. В блоке `<head>` настраиваем кодировку UTF-8 и даём имя вкладке через `<title>`.
5. Оставляем блок `<body>` готовым для добавления контента.

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <!-- Технические параметры страницы (не видны на экране) -->
    <meta charset="UTF-8">
    <title>Мой первый сайт</title>
  </head>
  <body>
    <!-- Всё видимое содержимое страницы пишется строго здесь -->
  </body>
</html>

```

* `<!DOCTYPE html>` - объявление типа документа. Оно стоит на самой первой строке и говорит браузеру: «Этот документ написан по современному стандарту HTML5». Без этой строчки старые браузеры могут отображать страницу некорректно.
* `<html>` ... `</html>` - главный корневой тег. Это контейнер для абсолютно всего кода сайта. Внутри него находятся только два тега-потомка: «голова» (`<head>`) и «тело» (`<body>`). Атрибут `lang="ru"` сообщает поисковикам и встроенным переводчикам, что основной язык текста - русский.
* `<head>` ... `</head>` - технический отсек («голова»). Всё, что находится внутри `<head>`, **не отображается** на самой веб-странице. Здесь размещается служебная информация:
* `<meta charset="UTF-8">` - кодировка символов (благодаря ей русский текст не превращается в непонятные знаки-кракозябры).
* `<title>` - заголовок страницы, который отображается на вкладке браузера и в закладках.

* `<body>` ... `</body>` - видимая часть («тело»). Всё, что пользователь видит на экране монитора или смартфона (тексты, картинки, кнопки, видео, таблицы), помещается **строго внутри** этого тега. Любой текст, написанный вне `<body>`, считается синтаксической ошибкой.

> **Проверка:** Откройте файл `index.html` двойным щелчком в любом браузере (Chrome, Яндекс, Edge). Должна открыться пустая белая страница, а на вкладке браузера появится надпись «Мой первый сайт».

### Наполнение базовыми тегами

Все видимые элементы на сайте создаются с помощью **тегов**. Большинство тегов парные: открывающий тег (например, `<p>`) задаёт начало блока, а закрывающий со слешем (`</p>`) - его конец. Одиночные теги (например, `<hr>`) закрывающей пары не требуют.

* `<h1>`–`<h3>` - заголовки разного уровня важности (от самого крупного к меньшему).
* `<p>` - обычный текстовый абзац.
* `<b>` и `<i>` - жирное и курсивное начертание текста внутри строки.
* `<hr>` - горизонтальная линия-разделитель блоков.
* `<ul>` и `<li>` - маркированный список с точками.

**Что делаем:**

1. Открываем `index.html` в редакторе кода.
2. Вставляем внутрь тега `<body>` блок текстовых элементов и список.

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Мой первый сайт</title>
  </head>
  <body>

    <!-- Заголовки разного уровня -->
    <h1>Главный заголовок страницы</h1>
    <h2>Подзаголовок раздела</h2>
    <h3>Небольшой подзаголовок</h3>

    <!-- Горизонтальная линия -->
    <hr>

    <!-- Текстовые абзацы и форматирование -->
    <p>Это обычный текстовый абзац на странице сайта.</p>
    <p>В тексте можно выделять слова: делать их <b>жирными</b> или <i>курсивными</i>.</p>

    <!-- Маркированный список -->
    <ul>
      <li>Первый пункт списка</li>
      <li>Второй пункт списка</li>
      <li>Третий пункт списка</li>
    </ul>

  </body>
</html>

```

> **Проверка:** Сохраните файл (`Ctrl + S`) и обновите вкладку в браузере (`F5`). На экране появятся заголовки разного размера, разделительная полоса, форматированный текст и список с маркерами.

### Самостоятельное задание

#### Статья на свободную тему

1. Придумайте тему статьи (любимая компьютерная игра, фильм, книга, домашнее животное или космос).
2. Замените главный `<h1>` на название вашей темы.
3. Создайте структуру статьи с помощью тегов `<h2>`: сделайте минимум два смысловых раздела (например, «История появления» и «Главные особенности»).
4. Напишите в каждом разделе минимум по одному абзацу `<p>` текста. Используйте внутри теги `<b>` и `<i>`, чтобы выделить главные термины.
5. Добавьте маркированный список `<ul>` с 3–4 пунктами `<li>` (список персонажей, системные требования, правила или интересные факты).

### Стилизация и медиа: стили, ссылки и картинки

Чистый HTML по умолчанию чёрно-белый. Чтобы изменить цвет текста, фон или выравнивание, используют **инлайн-стили** - специальный атрибут `style="..."`, который пишется прямо внутри открывающего тега.

Для добавления графики и переходов между страницами используются теги `<img>` и `<a>`:

* `<img src="..." width="...">` - одиночный тег картинки. В `src` указывается ссылка на изображение в интернете, а в `width` - его ширина в пикселях.
* `<a href="...">` - ссылка. Атрибут `href` задаёт адрес перехода.

**Что делаем:**

1. Добавляем цвет фона для страницы через `<body style="background-color: ...">`.
2. Центрируем и перекрашиваем главный заголовок.
3. Вставляем изображение из интернета и кликабельную ссылку-кнопку.

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Мой первый сайт</title>
  </head>
  <!-- Задаём светло-серый цвет фона для всей страницы -->
  <body style="background-color: #f4f4f9;">

    <!-- Заголовок синего цвета по центру экрана -->
    <h1 style="color: #1a4480; text-align: center;">Статья о технологиях</h1>

    <hr>

    <p style="font-size: 18px; color: #333333;">
      Компьютеры и интернет развиваются очень быстро. Вот пример иллюстрации из сети:
    </p>

    <!-- Картинка с фиксированной шириной 350 пикселей -->
    <img src="https://cdn-icons-png.flaticon.com/512/12402/12402358.png" width="350">

    <p>
      Подробнее о программировании можно почитать на внешнем ресурсе:
    </p>

    <!-- Ссылка с переходом на сайт Википедии -->
    <a href="https://ru.wikipedia.org" style="color: #d9381e; font-weight: bold;">
      Перейти на сайт Википедии
    </a>

  </body>
</html>

```

> **Проверка:** Обновите страницу в браузере. Фон станет светло-серым, заголовок переместится в центр и станет синим, под текстом загрузится картинка, а при нажатии на ссылку откроется страница Википедии.

### Задания для самостоятельной работы

#### Добавление медиа-контента

1. Найдите в интернете подходящую картинку по теме статьи:
* Нажмите по картинке правой кнопкой мыши $\rightarrow$ выберите **«Копировать URL картинки»** (или «Копировать адрес изображения»).


2. Вставьте тег `<img>` под первым разделом статьи и подставьте скопированную ссылку в атрибут `src`.
3. Подберите атрибут `width` (например, `width="400"` или `width="500"`), чтобы изображение выглядело аккуратно и не выходило за границы экрана.
4. Добавьте под картинкой ссылку `<a>` на видеоролик, трейлер или фанатскую энциклопедию по теме с атрибутом `target="_blank"`.

#### Инлайн-стили и оформление

1. **Цвет страницы:** Подберите и задайте тегу `<body>` оттенок фона через `background-color`, подходящий под атмосферу статьи (например, тёмный `#1e1e1e` для космоса или мягкий пастельный для животных).
2. **Оформление заголовков:** Покрасьте все теги `<h2>` в единый яркий цвет с помощью свойства `color: ...;`.
3. **Выравнивание и размер:** Увеличьте размер шрифта у первого абзаца с помощью `font-size: 20px;` и выровняйте подпись к картинке по центру с помощью `text-align: center;`.
4. **Цветная карточка факта:** Оберните один из абзацев в индивидуальный стиль с собственным фоном и цветом текста:

```html
<p style="background-color: #ffeaa7; color: #2d3436; padding: 10px;">
  Интересный факт: здесь напишите самую необычную деталь по теме.
</p>

```

#### Интерактивная кнопка-ссылка

Превратите ссылку в конце статьи в графическую кнопку.

1. Возьмите тег `<a href="...">` и добавьте в атрибут `style` несколько свойств одновременно (разделяя их точкой с запятой `;`):
* `background-color: #0984e3;` - фон кнопки.
* `color: #ffffff;` - белый цвет текста.
* `padding: 10px 20px;` - внутренние отступы, чтобы ссылка стала похожа на объёмную плашку.
* `text-decoration: none;` - убирает стандартное синее подчёркивание у ссылки.


2. Проверьте, что при клике на полученную кнопку в браузере открывается нужная страница.
